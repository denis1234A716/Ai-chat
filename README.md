# Нейросеть · Pollinations

Веб-чат с ИИ на публичном API Pollinations. Один HTML-файл, без сборки и сервера.

## Возможности

- Чат с выбором модели
- Генерация картинок
- Запуск HTML/JS/CSS/SVG кода
- Markdown, файлы, фото, голосовой ввод
- Поиск по чатам и сообщениям
- Экспорт/импорт
- Тёмная и светлая темы

## Защита

- AES-256-GCM + PBKDF2 (600k–2M)
- PIN, Duress, Panic, WebAuthn
- Автоблокировка, автоочистка буфера
- CSP без `unsafe-eval`, Trusted Types

## Запуск

Скачай `zalupa.html` и открой в браузере.

## Приватность

Все данные — только в `localStorage` браузера.
